# F11Fullscreen

Аддон для PulseSync, который добавляет переключение полноэкранного режима по нажатию **F11** — так же, как это работает в браузере

## Использование

Нажмите **F11** в любой момент работы с Яндекс Музыкой через PulseSync:
- первое нажатие — переход в полноэкранный режим
- повторное нажатие — выход из полноэкранного режима
